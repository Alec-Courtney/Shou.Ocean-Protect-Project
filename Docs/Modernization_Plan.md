# 前端现代化面板优化方案 (V5.0 Design Proposal)

## 1. 设计概述

本方案旨在将现有的“渔船离境智能预警系统”从一个传统的 Web 工具界面，升级为具备**指挥中心 (Command Center)** 质感的现代化数据可视化平台。

**核心理念**：
*   **沉浸感 (Immersion)**：通过深色模式和悬浮布局，最大化地图的可视区域，让用户感觉是在直接操作地图。
*   **信息层级 (Hierarchy)**：通过视觉权重的调整（字体大小、颜色对比、透明度），让关键预警信息从背景中跳出来。
*   **轻量化 (Weightless)**：摒弃厚重的侧边栏背景，全面采用高级玻璃拟态 (Advanced Glassmorphism)，使界面轻盈透气。

---

## 2. 视觉风格指南 (Visual Style Guide)

### 2.1 配色方案 (Dark Theme)

建议从当前的浅色系切换为**深色系**，以减少屏幕眩光，提升在长时间监控场景下的舒适度，并增强科技感。

*   **基底 (Background)**:
    *   面板背景: `rgba(15, 23, 42, 0.75)` (深蓝灰，高斯模糊)
    *   页面背景: `Esri World Imagery` (卫星图)
*   **边框与分割 (Borders)**:
    *   `rgba(255, 255, 255, 0.08)` (极细微的白线)
*   **状态色 (Status Colors)** - 采用高亮霓虹色:
    *   **Level 0 (安全)**: `#4ade80` (Neon Green)
    *   **Level 1 (已越界)**: `#ef4444` (Neon Red) + 呼吸光效
    *   **Level 2 (即将越界)**: `#f97316` (Neon Orange)
    *   **Level 3 (风险)**: `#facc15` (Neon Yellow)
*   **文本 (Typography)**:
    *   主要文字: `#f8fafc` (接近纯白)
    *   次要文字: `#94a3b8` (蓝灰色)

### 2.2 字体排印

引入系统级现代无衬线字体栈，如果是英文数字推荐使用等宽字体以增强数据感。

*   **主字体**: `'Inter', system-ui, -apple-system, sans-serif`
*   **数字/代码**: `'JetBrains Mono', 'Roboto Mono', monospace` (用于经纬度、速度、时间)

### 2.3 玻璃拟态 2.0 (Glassmorphism 2.0)

不仅仅是模糊，还需要添加噪点纹理和边缘高光，模拟磨砂玻璃的物理质感。

```css
.glass-panel {
    background: rgba(15, 23, 42, 0.6);
    backdrop-filter: blur(16px) saturate(180%);
    -webkit-backdrop-filter: blur(16px) saturate(180%);
    border: 1px solid rgba(255, 255, 255, 0.1);
    box-shadow: 
        0 4px 6px -1px rgba(0, 0, 0, 0.1), 
        0 2px 4px -1px rgba(0, 0, 0, 0.06),
        inset 0 0 20px rgba(255, 255, 255, 0.05); /* 内发光 */
    border-radius: 16px;
}
```

## 3. 布局重构 (Layout Re-architecture)

### 3.1 顶部：HUD 抬头显示栏 (Heads-Up Display)

将目前的 `map-brand-row` 和 `stat-grid` 整合为一个悬浮在顶部的**胶囊型或条形 HUD**。

*   **左侧**: 品牌 Logo + 系统名称 (紧凑排列)。
*   **中间**: 核心指标 (在线船只 | 当日预警 | 最高风险)。使用图标 + 数字的组合，移除冗余文字。
*   **右侧**: 连接状态 + 当前时间 + 快捷设置按钮。

### 3.2 左侧：可收纳的功能抽屉

将“历史查询”和“预警统计”改为**抽屉式 (Drawer)** 或 **图标导航 (Icon Sidebar)**。

*   **默认状态**: 仅显示一列图标（历史、统计、设置）。
*   **展开状态**: 点击图标后，向右滑出半透明面板显示详细内容。
*   **优势**: 彻底释放左侧屏幕空间，只有在需要查询时才占用视野。

### 3.3 右侧：监控面板 (悬浮卡片)

保留右侧作为实时监控区，但将全高侧边栏改为**上下分离的悬浮卡片**。

*   **右上卡片 (船只列表)**:
    *   限制最大高度，显示在线船只。
    *   列表项设计优化：左侧状态灯，中间船名(ID)，右侧图标指示类型。
*   **右下卡片 (详情与状态)**:
    *   仅在选中船只时显示。
    *   不再是简单的文字列表，而是仪表盘化（例如速度可以用一个半圆仪表显示，航向用指南针图标旋转表示）。

### 3.4 底部/中央：动态预警通知 (Toast Notifications)

*   **位置**: 现在的预警列表在右下角/左侧容易被忽视。建议将最新的高等级预警（Level 1/2）设计为**顶部中央的 Toast 弹窗**。
*   **样式**: 醒目的红色/橙色横幅，显示 5 秒后自动收起进入“通知中心”。
*   **通知中心**: 点击右上角的“铃声”图标，展开查看历史预警列表（即原来的预警列表面板）。

## 4. 组件细节设计

### 4.1 船只图标 (Vessel Markers)

*   **动态方向**: 目前图标是静态的。建议使用 Canvas 或 SVG 绘制三角形/船形图标，并根据 `bearing` 属性**实时旋转**，直观显示航向。
*   **状态光环**: 预警船只周围增加 CSS 动画产生的扩散光环 (Ripple Effect)，让用户一眼定位风险源。

### 4.2 迷你图表 (Sparklines)

*   在“当日预警”统计卡片中，添加一个微型的折线图（Sparkline），显示过去 24 小时的预警数量趋势，让“数字”变成“趋势”。

### 4.3 地图控件

*   将“视角回中”、“切换底图”、“显示标签”等按钮整合成一个**垂直的悬浮工具条 (Floating Toolbar)**，置于屏幕右下角，样式参考 Google Maps 或 Mapbox 的标准控件。

---

## 5. 交互与动效

*   **平滑过渡**: 所有面板的出现/消失、数值的变化都应有 `transition: all 0.3s cubic-bezier(...)` 过渡。
*   **聚焦动画**: 点击预警通知时，地图不仅飞到 (`flyTo`) 目标位置，还可以稍微倾斜视角 (Pitch)，增加 3D 临场感（如果 Leaflet 插件支持或升级到 Mapbox GL JS）。
*   **骨架屏 (Skeleton Screen)**: 数据加载或连接中时，显示半透明的占位骨架，而不是生硬的“--”或空白。

## 6. 实施步骤建议

1.  **CSS 变量重定义**: 首先在 `style.css` 中定义新的深色系颜色变量。
2.  **结构调整**: 修改 `index.html`，将侧边栏容器改为悬浮容器类。
3.  **样式覆盖**: 编写新的 CSS 类实现 Glassmorphism 2.0。
4.  **JS 适配**: 更新 `main.js` 中的图表更新逻辑和动态类名切换，适配新的 DOM 结构。

此方案在保留现有业务逻辑（Socket.IO, Leaflet）的基础上，通过 CSS3 和 HTML5 的重构，即可实现从 V4.7 到 V5.0 的视觉跨越。
